SANW: LOCAL OPERATOR COMMANDS

Read local/README.txt and the final validation receipt before execution.
These commands use the rebuilt wrapper.
They do not validate themselves or replace the scientific contracts.
Use x86_64 Linux or WSL2 with Docker.
Docker explicitly runs linux/amd64 images.
ARM emulation can be substantially slower.
Run every command from the repository root.

Clone and prepare

git clone --branch local-handoff-20261005 https://github.com/priyankjairaj100/SANW.git
cd SANW
git rev-parse HEAD
docker build --platform linux/amd64 -t sanw-v10-local - < local/Dockerfile
bash local/docker.sh prepare
bash local/docker.sh prepare --execute
bash local/docker.sh preflight
bash local/docker.sh status

The final publication message must identify the exact handoff commit or branch.
Check out that revision if it differs from the default branch.
Do not execute a revision that lacks these handoff files.

The prepare phase first reconstructs 4805 exact scientific source and evidence files from the snapshot.
It then reconstructs exact input archives and restores training/development inputs and completed fits.
No separate host Python command is required.
The restorer upgrades only recognized historical file bytes and refuses unknown local changes.
The Docker wrapper mounts this checkout at the historical absolute root.
It avoids edits to bound scientific ledgers.
It uses CPU fitting with the recorded runtime versions.
The frozen fitting code works on precomputed features and follows the audited CPU recipe.
Having a GPU does not automatically accelerate this unchanged program.
Do not replace that recipe with a GPU implementation without separate validation.

Command pattern

bash local/docker.sh PHASE
bash local/docker.sh PHASE --execute

The first command prints the plan.
The second command executes it.
Inspect the printed plan before execution.
Run one phase at a time and check its exit code.
Do not continue after a failure.

Return results

bash local/docker.sh report --full-evidence --execute

Send the generated local/reports archive and JSON manifest to the research chat.
The full report includes V10 checkpoints, predictions, paired counts, bootstrap arrays, logs, and source identities.
It also includes fresh completion, metadata, and data-manifest records.
It excludes feature caches, raw images, model downloads, and fresh features.npz.
Keep those excluded assets locally with their recorded hashes.
For a quick status update only, omit --full-evidence to create a compact report.
The compact report does not support every numerical audit.

Interruption handling

Completed fit directories skip fit launch; they still require their scientific audits.
Incomplete fits move into local/retired before restarting from epoch zero.
If a multi-command phase stops, inspect its logs before retrying.
Existing output files can cause a stop to prevent overwriting.
Do not delete valid outputs merely to make a whole phase rerun.
Use the wrapper's printed remaining commands only after checking their prerequisites.
